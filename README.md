# 🚀 Bootstrap 5 Geliştirici Profil Kartı

Tamamen **Bootstrap 5** sınıfları kullanılarak, sıfır özel CSS ile tasarlanmış modern ve duyarlı (responsive) bir geliştirici profil kartı projesi.

## 🔗 Canlı Önizleme
Projeyi canlı olarak incelemek için tıklayın: **[Canlı Demo](https://bilaldemir-dev.github.io/bootstrap-profil-karti/)**

## ✨ Özellikler
* **Hiç Özel CSS Yok:** Tüm tasarım Bootstrap'in yerleşik utility (yardımcı) sınıflarıyla yapılmıştır.
* **Gölgeleme & Kenar Yuvarlatma:** `shadow` ve `rounded` sınıfları ile tasarıma derinlik katıldı.
* **Buton Grupları:** `btn-group` kullanılarak çalışma alanları düzenli bir yapıda sunuldu.
* **Etkileşimli Hover Durumları:** `btn-outline-*` sınıfları ile araç etiketleri için dinamik renk dolumları sağlandı.
* **Duyarlı Izgara (Grid) Sistemi:** Mobil ve masaüstü uyumluluğu için `d-grid` yapısı kullanıldı.

## 🛠️ Kullanılan Teknolojiler
* HTML5
* Bootstrap 5.3 (CDN üzerinden)
* UI Avatars API (Dinamik profil fotoğrafı)
